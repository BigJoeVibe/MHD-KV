## Klíčová implementační rozhodnutí

### Typy dne — 5, ne 3

Původní appka měla 3 typy dne. F1 zavedl 5:

| Klíč | Kdy |
|---|---|
| `workday` | Po–Pá, mimo svátky a prázdniny |
| `workday_holiday` | Po–Pá v prázdninovém období |
| `weekend` | So, Ne + státní svátky |
| `xmas_night` | 24.12. 18:00 → 25.12. 13:00 |
| `nye_night` | 31.12. 22:00 → 1.1. 13:00 |

Fallback v `getEffectiveDayType()`: `xmas_night→weekend`, `nye_night→weekend`, `workday_holiday→workday`.
Linka 9 má `workday_holiday: null` → padá na `workday`.

### Per-route notes (ne globální)

Každá route má vlastní `notes: { "L": "text", ... }`. Legenda v departure kartách
zobrazuje jen písmena přítomná v aktuálně viditelných spojích. Legenda v jízdním
řádu zobrazuje vždy celou notes mapu route.

### Warnings systém

```js
warnings: [{ text: "Výluka do 30.6.2026", validUntil: "2026-06-30" }]
```

Funkce `getActiveWarnings(route, now)` porovná dnešní datum s `validUntil`
a skryje warning po expiraci. Linka 9 má aktivní výluku (data z d-9a/).

### Noční linka 51 — přechod přes půlnoc

```js
if (nowMin >= 1080 && h < 7)  totalMin += 1440;
if (nowMin < 420  && h >= 22) totalMin -= 1440;
```

Odjezdy jsou zadány s hodinami 22–23 (večer) i 0–6 (ráno) a funkce to správně
řadí bez duplicit.

### Header formát

`formatCzechDate(date) + ' · ' + formatTime(h, m)` → „úterý, 12. května · 20:00"
Typ dne se v hlavičce nezobrazuje (bylo odstraněno na žádost uživatele).
